## PRODUCTION NOTES

### Video Specifications
- **Resolution:** 4K (3840x2160) recommended, 1080p (1920x1080) minimum
- **Frame Rate:** 24fps for cinematic sections, 30fps for demo/motion
- **Aspect Ratio:** 16:9 horizontal
- **Duration:** Generate 8-10 second clips, trim as needed
- **Format:** MP4 with H.264/H.265 codec

### Color Consistency
```
Primary Brand:     #14B981 (Teal/Emerald Green)
Secondary:         #FFFFFF (Pure White)
Dark Background:   #1A1A2E (Deep Navy)
Accent Warm:       #FFD93D (Gold) - use sparingly
Neutral Light:     #F8F9FA (Off-White)
Warning/Expiring:  #F59E0B (Amber)
```

## PROMPT TIPS FOR VEO 3

1. **Be Specific:** Include camera movement, lighting direction, mood, and style
2. **Mention Quality:** Always include "4K quality" or "cinematic quality"
3. **Color Reference:** Use hex codes (#14B981) for brand color consistency
4. **Avoid Text:** Veo 3 struggles with text - add all text in post-production
5. **Loop Requirement:** For backgrounds, specify "seamless loop-able"
6. **No Faces:** Specify "no clearly visible faces" for easier editing and universal feel
7. **Context Cues:** Include environment details (kos room, student items) for authenticity
